# Screenshot provenance

The five JPEGs in this directory are resized, metadata-free copies of reviewed screenshots already present in Atelier's original public catalogue walkthrough. They show the existing gallery, timeline, exhibition, discovery, and display interfaces. They are historical captures; current fresh installations contain no collection records.

The legacy outreach capture is not included because correspondence, contact activity, and follow-up details are private operational data. It was removed from the current source tree; this does not erase earlier Git commits.

The artwork in these captures belongs to its respective rights holders. The repository's MIT license covers software, not ownership or redistribution rights for the depicted artwork. New screenshots should use appropriately licensed art and sample data, and receive both a visual and metadata review before publication.
